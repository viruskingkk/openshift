Project Onboarding Portal (標準化專案接入)

▼ 接入操作步驟

1. New Project

填寫 Project、Room ID、DB 等基本資料。

2. Preview / Register

預覽與 Register，寫入 GitOps 並 atomic commit 到 main。

3. Readiness

確認 GitOps、DB、Redis、Secret、Image、Argo CD 就緒。

4. Activate

驗證通過後 atomic commit Product Cutover 到 main。

⚠️ 重要：Activate 會先完成 Readiness 驗證，驗證通過後直接 atomic commit Product Cutover 到 main，再由 Argo CD 啟用切換。
🔄 Disable：直接 atomic commit 完整 Product Rollback 到 main，Commit 成功後停用 Product workloads 並恢復 Legacy backend。
